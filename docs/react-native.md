# React Native integration

Install `react-native-dash-ota`, wire the per-flavour native config, and wrap your app in
`<DashOtaProvider>`.

Full guide: **https://scripting-bear.github.io/dash-ota/docs/react-native/installation**

- [Android setup](https://scripting-bear.github.io/dash-ota/docs/react-native/android-setup)
- [iOS setup](https://scripting-bear.github.io/dash-ota/docs/react-native/ios-setup)
- [`useOtaUpdate()`](https://scripting-bear.github.io/dash-ota/docs/react-native/use-ota-update)
