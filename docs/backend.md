# Backend

Mount `dashOtaMiddleware()` into Express or any Connect-style app, or run it standalone. It
distributes pre-signed releases and never holds a signing key.

Full guide: **https://scripting-bear.github.io/dash-ota/docs/backend/installation**

- [Configuration](https://scripting-bear.github.io/dash-ota/docs/backend/configuration)
- [Storage & providers](https://scripting-bear.github.io/dash-ota/docs/backend/providers)
- [Deployment](https://scripting-bear.github.io/dash-ota/docs/backend/deployment)

The wire protocol is specified in [PROTOCOL.md](./PROTOCOL.md).
